# mtncloud_router (Resource)

Manages an MTN Cloud router using the MTN neutronRouter offering. Other router backends are not supported.

## Example Usage

```terraform
# MTN selects its neutronRouter backend automatically.
resource "mtncloud_router" "app" {
  name          = "app-router"
  group         = "MTNNG_CLOUD_AZ_1"
  resource_pool = "my-project"

  # Morpheus subnet IDs belonging to the selected MTN resource pool.
  internal_subnet_ids = [123]

  # Optional Morpheus external network ID for an external gateway.
  # external_network_id = 34
}
```

## MTN Cloud configuration

This resource supports only MTN's `neutronRouter` offering. The backend type is
selected automatically; there is no router-type selector or generic JSON input.

Set a group and resource pool on this resource or inherit them from the provider.
`internal_subnet_ids` contains Morpheus subnet IDs, not network IDs or OpenStack
UUIDs. These subnets must belong to the selected resource pool. Optionally set
`external_network_id` to a Morpheus external network ID.

When a group has multiple clouds, set `cloud_id` explicitly. The provider resolves
the resource pool within that cloud and sends MTN's `pool-<id>` code in
`config.poolId`, which the REST provisioning backend requires.

Configuration changes replace the router. Creation waits up to five minutes for
a ready backend status and reports failed provisioning. Deletion waits up to five
minutes for the router to disappear. The ID is saved before waiting, so a failed
create can still be cleaned up with Terraform.

Import reads attached subnet and pool information from the router's internal
networks. Routers without internal subnet attachments cannot be fully reconstructed
for this resource. Separate NAT, route, and firewall-rule management is not included.

## Schema

### Required

- `internal_subnet_ids` (Set of Number) Morpheus internal subnet IDs to attach. Changes replace the router.
- `name` (String) Router name. Changes replace the router.

### Optional

- `cloud_id` (Number) MTN Cloud ID. Inferred only when the group has exactly one cloud. Changes replace the router.
- `enabled` (Boolean) Whether the router is enabled at creation. Changes replace the router.
- `external_network_id` (Number) Optional Morpheus external network ID. Changes replace the router.
- `group` (String) Group name; defaults to the provider group. Changes replace the router. Shared routers are not supported.
- `resource_pool` (String) MTN resource pool name/code, inherited from the provider when omitted. Changes replace the router.

### Read-Only

- `external_ip` (String) External IP, if assigned.
- `id` (String) Numeric router ID.
- `status` (String) Observed MTN router status. Creation waits up to five minutes for readiness.
- `type` (String) MTN router backend code (neutronRouter).

## Import

Import is supported using the following syntax:

```shell
terraform import mtncloud_router.app 123
```

# mtncloud_external_network (Data Source)

Looks up an external network by exact name for an MTN router. Uses router gateway options, which can include networks unavailable through mtncloud_network.

## Example Usage

```terraform
# Group and resource_pool can be inherited from the provider.
data "mtncloud_external_network" "public" {
  name          = "public-network-01"
  group         = "MTNNG_CLOUD_AZ_1"
  resource_pool = "my-project"
}

output "external_network_id" {
  value = tonumber(data.mtncloud_external_network.public.id)
}
```

## Schema

### Required

- `name` (String) Exact external network name, for example public-network-01. Ambiguous names are rejected.

### Optional

- `cloud_id` (Number) Cloud/zone ID. Inferred only when the selected group has exactly one cloud.
- `group` (String) Group name. Defaults to the provider group.
- `resource_pool` (String) Resource pool name or code. Defaults to the provider resource_pool. Options are scoped to this project.

### Read-Only

- `id` (String) Morpheus external network ID.

# mtncloud_external_networks (Data Source)

Lists external networks available to an MTN router in the selected group, cloud, and resource pool.

## Example Usage

```terraform
data "mtncloud_external_networks" "available" {
  group         = "MTNNG_CLOUD_AZ_1"
  resource_pool = "my-project"
}

output "external_networks" {
  value = data.mtncloud_external_networks.available.networks
}
```

## Schema

### Optional

- `cloud_id` (Number) Cloud/zone ID. Inferred only when the selected group has exactly one cloud.
- `group` (String) Group name. Defaults to the provider group.
- `resource_pool` (String) Resource pool name or code. Defaults to the provider resource_pool. Options are scoped to this project.

### Read-Only

- `id` (String) Identifier of the group, cloud, and resource pool used for discovery.
- `networks` (Attributes List) Available external networks. IDs are Morpheus network IDs suitable for mtncloud_router.external_network_id, not OpenStack UUIDs. (see [below for nested schema](#nestedatt--networks))
